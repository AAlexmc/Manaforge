> [!TIP]
> **«Какие колоды я могу собрать из того, что у меня УЖЕ есть?»** Вот вопрос, на который ни одно приложение по Magic толком не отвечает — и единственная причина существования ManaForge. Остальные помогают *каталогизировать* вашу коробку с картами; это — превращает её в колоды, готовые к тасовке.

Все мы через это проходили: коробка, набитая картами из бустеров, стартовых колод и доставшихся по наследству ящиков… и ни малейшего понятия, что из всего этого собрать. ManaForge сделан игроками для игроков: **бесплатно, без рекламы, без премиума, без аккаунтов и с полностью открытым кодом.**

<a id="forge"></a>
## ⚒️ Forge: генератор колод

Отдайте ему свою коллекцию — и он вернёт **полные колоды из 60 карт**, собранные так, как собрал бы их бывалый игрок. Вот как он думает:

<p align="center">
  <img src="../assets/forge-flow.svg" alt="Коллекция → Синергии → Мана-кривая → Валидатор → Колоды с планом игры" width="100%">
</p>

- 🏔️ **Правильная мана-кривая** — земли под архетип, источники распределены по цветовым символам, кривая проверена. Никаких колод с 15 землями.
- 🧬 **Найденные синергии** — Forge читает текст правил каждой карты и находит ваши темы: высасывание жизни, жертвование, артефакты, го-вайд, спеллслингер, жетоны…
- 🗺️ **План игры с объяснением** — ход за ходом, плюс раскрывающийся блок *«Почему эта колода работает?»* для тех, кому нужна теория.
- 🤝 **Кодекс чести** — движок никогда не берёт карты, которых у вас нет, никогда не нарушает лимит копий, а вместо того чтобы выдать поломанную колоду, объяснит почему и предложит альтернативу.
- 🎯 **Выберите свой стиль** — навяжите племя (Эльфы, Зомби, Драконы… 24 отобранных, плюс любой подтип, где хватает существ) или механическую тему — и движок подчинится. В режиме Авто он сам находит то, что ваша коллекция отыгрывает лучше всего.
- ⚔️ **Глубокая ковка** — прежде чем показаться вам, колоды-кандидаты играют сотни партий друг против друга: итоговый рейтинг учитывает, как они ведут себя на деле, а не только оценку на бумаге.
- 🎲 **Настоящая вероятность** — стабильность (приходят ли земли вовремя?) и играбельная кривая считаются гипергеометрической математикой; небазовые земли (шоки, чеки, фетчи) учитываются по тому, что они реально делают.
- 📤 **Экспорт в один тап** — скопируйте список и вставьте его в Moxfield, MTG Arena или Discord вашей игровой компании.

<a id="download"></a>
## 🚀 Скачайте и откройте

Зайдите в [**Releases**](https://github.com/AAlexmc/Manaforge/releases) и возьмите zip для вашей системы. Ни установщика, ни аккаунтов: распаковали и открыли.

| Система | Что делать |
|---|---|
| **Windows** | Распакуйте и внутри папки `ManaForge` откройте `manaforge.exe`. В первый раз Windows предупредит, что не знает программу: *Подробнее → Выполнить в любом случае* (она не подписана; код лежит прямо здесь — проверяйте). |
| **macOS** | Распакуйте и откройте приложение один раз (появится предупреждение); затем зайдите в *Системные настройки → Конфиденциальность и безопасность → Открыть всё равно*. (Начиная с macOS 15 правый клик → Открыть предупреждение уже не обходит.) |
| **Linux** | Распакуйте и внутри папки `ManaForge` запустите `./manaforge`. Чтобы приложение появилось в меню со своей иконкой: `./instalar.sh` (всё кладётся в `~/.local`, без sudo; удаляется через `./instalar.sh --desinstalar`). |

**Проверьте, что скачали**: каждый релиз публикует `SHA256SUMS.txt` с отпечатками трёх zip-архивов. На Linux и macOS — `sha256sum -c SHA256SUMS.txt` (или `shasum -a 256 -c`); на Windows — `Get-FileHash ManaForge-Windows.zip`.

При первом запуске приложение скачивает **~36 МБ** данных (карты и цены Scryfall, история цен и отпечатки для сканера) и показывает прогресс. Дальше всё работает офлайн.

Затем: **импортируйте коллекцию** из CSV, **отсканируйте** карты веб-камерой или по фото — или идите сразу в **⚒️ Forge** и соберите колоду из заданной коллекции, даже пока своей у вас ещё нет.

### Предпочитаете собрать сами?

```bash
# Flutter, канал stable: https://docs.flutter.dev/get-started/install
# (на Windows нужна Visual Studio с «Разработка классических приложений на C++»)
git clone https://github.com/AAlexmc/Manaforge.git
cd Manaforge/app
flutter run -d linux     # или -d windows / -d macos
```

Нативные обёртки для Linux, Windows и macOS плюс `pubspec.lock` лежат в репозитории, так что проект собирается как есть на всех трёх.

<a id="architecture"></a>
## 🔧 Как это устроено

| Папка | Что там живёт |
|---|---|
| [`app/`](../../app) | Flutter-приложение — одна кодовая база для Windows, macOS и Linux (а однажды и для мобильных) |
| [`forge_engine/`](../../forge_engine) | Движок колод на Dart: кривая, валидатор, классификатор и генератор |
| [`engine-reference/`](../../engine-reference) | Тот же движок на Python: **каноничный, покрытый тестами эталон** алгоритма |
| [`scripts/`](../../scripts) | Пайплайн данных: bulk Scryfall → SQLite, выполняется только в GitHub Actions |
| [`DesignSystem/`](../../DesignSystem) | Дизайн-токены, SVG-иконки маны и спецификации компонентов |
| [`docs/`](../../docs) | Архитектура данных, алгоритм Forge и устройство сканера |

Проект определяют два решения. Первое: **движок существует в двух экземплярах** — Python как исполняемая спецификация с тестами, Dart как реализация, которая едет в приложении; при расхождении прав Python. Второе: **база данных собирает себя сама** — workflow ежемесячно скачивает bulk Scryfall и публикует SQLite как [релиз](https://github.com/AAlexmc/Manaforge/releases/tag/card-db-latest), который приложение забирает при первом запуске.

```bash
cd engine-reference && python3 -m pytest tests/   # тесты алгоритма (канон)
cd forge_engine && dart test                      # тесты движка приложения
cd app && flutter test                            # тесты приложения
```

## 🗺️ Дорожная карта

- [x] **Фаза 1 — Фундамент**: движок кривой и валидатор (Python + Dart), дизайн-система, CI
- [x] **Фаза 2 — Данные**: пайплайн bulk Scryfall → SQLite с автоматическим ежемесячным релизом
- [x] **Фаза 3 — Генератор**: функциональная классификация, темы, скоринг и жадная сборка
- [x] **Фаза 4 — Приложение v0.2**: коллекция с поиском ES/EN, импорт CSV, Forge с каруселью и планом игры
- [x] **Фаза 5 — Полноценный десктоп**: автоматические сборки Windows/macOS/Linux в Releases, сохранение колод, горячие клавиши и окно, помнящее своё место
- [x] **Фаза 6 — Шлифовка**: цены и стоимость коллекции, P&L покупок, легальность по форматам и **10 полных языков**
- [x] **Фаза 7 — Сканер**: перцептивные отпечатки, генерируемые в CI + веб-камера/фото, 100 % на устройстве ([как это работает изнутри](../reconocimiento-cartas.md))
- [x] **Фаза 7½ — Forge v2**: вероятностная манабаза, оценка по стабильности и кривой, племенные темы и реаниматор, селектор стиля, глубокая ковка и испанские названия карт
- [ ] **Фаза 8 — Обмены и сообщество**: обмены между коллекциями плюс всё, что попросит [ящик предложений](https://github.com/AAlexmc/Manaforge/issues/new/choose)
- [ ] **Фаза 9 — Мобильные (если попросит сообщество)**: Android и iOS/TestFlight — код готов; не хватает только аккаунтов в магазинах приложений
